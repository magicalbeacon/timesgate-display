# Verification

Release 0.5.3, 18 October 2026. Built and reviewed in a cloud x64 Linux workspace with Node 24.19.0. This is a Docker source package, not a prebuilt image.

## Passed

- All 238 unit/integration tests pass with NODE_OPTIONS=--max-old-space-size=128 in both the personalized source and sanitized public staging. Independent read-only review also passes all 238 tests and found no release-blocking issue; its separate 150,000-case differential check passes.
- Fresh Docker COPY-equivalent staging includes only src, test, package.json, package-lock.json, .dockerignore and .env.example. Locked offline npm ci from a verified package cache and the same complete test suite pass there. This is not an actual Docker build.
- The previous six explicit profiles remain covered: static, typing animation or sleeping animation, each with 1-second or 10-second text polling. Static/10-second remains the default. Parsing rejects missing apply, invalid values, duplicate flags, extra properties and other-target options. Queued profiles are fingerprint-bound to the device, existing configuration and callback origin; altered, expired or stopped requests cannot execute.
- Every setup sends exactly one unchanged-form Draw/SendHttpItemList to internal LCD3 (human screen 4). One countdown item retains TextId 26, font 188, y108 and the existing URL. Tests enforce the complete payload and reject other commands, targets, URLs, masks and bounds. Defaults reproduce the 0.5.1 static/10-second layout.
- Whole-main/CLI tests intercept every outbound request. Startup discards queued writes, starts an idle timer and remains unarmed. Explicit experiments target LCD3 only. Browser timer actions, GIF GETs, countdown reads and phase changes never send device commands. Uncertain or rejected writes halt once, consume the request and do not retry. Prior halt state remains after successful native setup. Stock tests still target only LCD0/1.
- Timer tests cover automatic short breaks at focus deadlines, 15-minute breaks every fourth completed focus, manual-only next focus, monotonic elapsed time, late polling through both deadlines, single counting, pause/resume, reset/restart clearing the count, revision guards and browser stale-freeze behavior. Host/Origin checks, per-process CSRF tokens, duplicate-header rejection, POST-only strict bodies, bounded reads, no CORS and framing protection remain intact. These controls are not user authentication; use only a trusted LAN.
- Both production animations are 128x128 with six full opaque frames and a shared global palette. Typing is 6,889 bytes with a 2,340 ms loop; sleeping is 5,468 bytes with a 3,600 ms loop. Both loop indefinitely. Index 0 is unused in every decoded frame; y108-123 stays clear for text. Five dependency-free Node tests parse the actual GIF structure and independently decode LZW pixels, checking dimensions, frames, timing, palette, opacity, motion bounds and footer. The tests run without Pillow or assets in the Docker COPY context.
- Both authoring-only Pillow scripts' --check validates production/embedded byte equality, decoded frames, preview metadata and deterministic regeneration. The old static cat, legacy art and endpoints remain unchanged. Animated responses are fixed bytes through focus, break, pause and reset. No runtime dependency, per-frame upload, phase-driven background switch or device-animation status claim was added.
- The 128/512 software animation previews and contact sheets were inspected. Their 25:00 or 05:00 text is illustrative and uses an approximate native font, not a device photograph or live timer. The engineering frame/byte budget is not a claimed firmware limit.
- Public .env.example keeps the generic AAPL,MSFT example and blank credentials; it does not disclose an individual watchlist. Fixed Singapore weather examples are demonstration geography, not a detected user location. Upgrade instructions preserve the existing .env and backup folder; no new environment key or credential is required. Stock and weather holds remain. Weather/market/writer/control, native layout, GIF assets and HTTP authorization implementation files are unchanged by this release. Only timer state, dashboard presentation, release version, tests and documentation change.
- The package allowlist excludes .env, credentials, installed dependencies, runtime state, caches, provider snapshots, layouts, logs and archive files. No brokerage account or holdings data is included. Synthetic secret markers appear only in tests and are checked for non-disclosure.

## Limits and outstanding physical checks

- Docker executable/daemon is unavailable here. No real Docker build, arm64 startup, Pi CPU/memory measurement, or physical-device request was performed for this release. A COPY-equivalent test is not a substitute for those checks.
- One-second native text polling has prior Times Gate source/report evidence, but exact timing, firmware stability and animated BackgroudGif with the countdown overlay still require the separate screen-4 experiments. API acknowledgement does not prove rendering. Network/device timing can skip displayed seconds.
- A locally looping cat, if supported, continues during idle, pause, break, completion and server outage. Selecting the sleeping image is a separate CLI action; timer phase changes do not switch it. It is decorative, not an indication of a running timer or healthy connection. Lost polling can leave the physical countdown frozen. The dashboard is the place to check phase, pause, session count and connectivity. Its counter and timer are in-memory and clear on Reset or server restart.
- A previous weather setup failure, if present, is not addressed by this release. No weather retry or speculative stock Loading fix is included. Screen 3 is never targeted, but undocumented shared firmware effects cannot be ruled out. All physical setup remains explicit.
- No full visual browser automation pass, TypeScript static compiler pass or completed vulnerability audit is claimed. No private Finnhub credentials were used; provider and device behavior is tested with mocks.
